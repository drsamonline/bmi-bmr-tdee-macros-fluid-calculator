# Changelog

## 2.5.0 — 2026-11-01

Repository presentation, and the release icons that were missing.

- **The released binaries now carry this app's own icon.** The build pipeline looks for
  `docs/play/icon.png` (or `icon.svg`) inside the app source and stamps it into the Windows
  executable and the Android launcher. The artwork lived one level up, at `docs/icon.svg`, so
  every release shipped with the builder's fallback glyph instead. It is now written where the
  pipeline looks, by `scripts/make_icons.py`, at every size including a multi-size `.ico`.
- **Badges are files, not requests.** `scripts/badges.py` draws them into `docs/assets/` and both
  the README and the landing page reference them by relative path. An offline-first app should not
  need an image service to describe itself, and the previous shields.io badges broke the page's own
  promise on the first screen.
- **A landing page of its own.** The page was rebuilt as a different object from the app — paper,
  a serif display face and amber ink against the app's pale teal instrument panel. Light is the
  base palette, the system preference decides the first paint, and a toggle in the header overrides
  it under its own storage key (`chc-landing-theme`), so setting the page does not restyle the app.
- **The demo is the app, not a picture of it.** The landing page embeds the real calculator in a
  frame and drives it with four guided buttons (a sample patient, the working panel, the clinical
  extras, the language switch). A poster sits behind the frame and the frame is revealed only when
  the app's own DOM is present, so a blocked frame shows the product rather than an empty box.
- **Screenshots of the real app**, desk and phone, taken by `scripts/shot.py` — which serves
  `docs/` over a throwaway local HTTP server, because Chromium refuses a `file://` frame from a
  `file://` parent and the embedded demo photographed as a blank rectangle.
- Fixed: the landing page footer claimed MIT while `LICENSE` is PolyForm Noncommercial 1.0.0, and
  the JSON-LD declared the same. Both now say what the licence says.
- Fixed: the Open Graph card was generated by socialify.git.ci, an external service. It is now
  `docs/assets/og.png`, drawn locally.

## 2.2.1 — 2026-10-25

- **Licence: PolyForm Noncommercial 1.0.0.** Every repository now carries the canonical text
  from polyformproject.org with the Required Notice line, and the four places a repo states
  its licence agree: LICENSE, the SPDX headers, the README and package.json.
- **The public demo is the app.** A build now fails if `docs/play/index.html` is not the app,
  because a demo running older code is two code paths for one program.
